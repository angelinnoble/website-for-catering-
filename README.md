# 🍽️ St. Mary's Catering Website

A modern and elegant catering website designed for **St. Mary's Caterers & Events**. The website showcases catering services, menu offerings, event galleries, company information, and contact details in a luxurious black-and-white design.

## ✨ Features

- 🏠 Modern Home Page
- 📖 About Us Page
- 🍴 Menu Showcase
- 🖼️ Image & Video Gallery
- 📞 Contact Page
- 💬 WhatsApp Inquiry Integration
- 📍 Location & Contact Information
- 📱 Fully Responsive Design
- 🎨 Luxury Black & White Theme
- ⚡ Smooth Animations & Hover Effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome Icons


2. Open the project folder

```bash

```

3. Open `index.html` in your browser.
